SYS.01  PRIVACY POLICY

Privacy Policy

Last updated 17 November 2026

A.R.E.S is a personal desktop app used only by its owner, on the owner's own computer. There is no A.R.E.S server, no user accounts, no analytics and no advertising. The developer does not collect, receive or store anyone's data.

Google user data A.R.E.S accesses

  • Gmail (read-only, gmail.readonly): email metadata (sender, subject, date, read/unread) and message content, so A.R.E.S can show the inbox, open an email and summarise it. It never sends, deletes or modifies email.
  • Google Calendar (calendar.events): event titles, times and locations, to show the schedule. Changes happen only after the owner confirms them on screen, and A.R.E.S only moves or deletes events it created itself.

How the data is used and stored

  • Data is shown on the owner's own screen and kept on the owner's own computer. The Google sign-in token and a cache of email summaries are stored in local files on that computer.
  • To write email summaries, reply suggestions and chat answers, the relevant text is sent to Anthropic's Claude API. To read text aloud, the text is sent to ElevenLabs. These services process it to return a result for the owner; it is not sold or used for advertising.
  • Google user data is never sold, never used for advertising, never shared with anyone else, and never used to train AI models.

Limited Use

A.R.E.S's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and deleting data

The owner can remove A.R.E.S's access at any time from their Google Account under Security → Third-party apps & services, and can delete all locally stored data by deleting A.R.E.S's config folder.

Contact

Questions about this policy can be sent to the owner through the GitHub account that hosts this site.
